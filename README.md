# STEEL Restaurant & Cafe — Demo

نسخة عرض (واجهة أمامية فقط) لموقع مطعم STEEL في إربد. مبنية بـ Vue 3 + Vite.

## التشغيل محلياً
```bash
npm install
npm run dev
```

## الرفع على Vercel
1. ارفع المجلد إلى مستودع GitHub.
2. من Vercel: **Add New → Project → Import** واختر المستودع.
3. Vercel يتعرّف على Vite تلقائياً (Build: `npm run build`، Output: `dist`). اضغط Deploy.

## أين أعدّل؟
| الملف | ماذا فيه |
|---|---|
| `src/site.js` | رقم واتساب الحجوزات، الهواتف، رابط فيسبوك، إحداثيات الخريطة |
| `src/i18n.js` | كل النصوص بالعربي والإنجليزي + أصناف القائمة والأسعار |
| `src/styles.css` | الألوان والخطوط (المتغيرات أعلى الملف) |

## الصور
ضع الصور في `public/img/` بهذه الأسماء، وتظهر تلقائياً مكان الخانات الرمادية:

| الملف | مكانها |
|---|---|
| `hero.jpg` | خلفية الواجهة الرئيسية (عرضي، 1920px تقريباً) |
| `about-1.jpg` | القاعة الداخلية (طولي) |
| `about-2.jpg` | طبق مميز |
| `g1.jpg` … `g5.jpg` | معرض الصور: التراس، الفطور، طبق رئيسي، الحلويات، السهرة |

## قبل الإطلاق الرسمي
- احذف سطر `<meta name="robots" content="noindex, nofollow">` من `index.html`.
- احذف شريط "نسخة عرض تجريبية" (`demo-ribbon` في `src/App.vue`).
- استبدل أصناف القائمة التجريبية بقائمة المطعم الحقيقية.
- تأكد من ساعات العمل ورقم واتساب الحجوزات مع المطعم.
